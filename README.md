**Session Overview **
Attendees will explore the BB84 Quantum Key Distribution (QKD) Protocol through an interactive, hands-on workshop combining theoretical understanding and conceptual demonstration. Participants will witness real-time key generation and distribution through an optical experiment setup using led laser, polarizers, beam splitter, photodiodes, and Raspberry Pi. The workshop will provide insights into light polarization properties, protocol mechanics, the quantum observer effect, and practical experience of running a simulation of BB84 on a simulator and real quantum computer using Qiskit.
